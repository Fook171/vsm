# Static Web Project

This is a simple static web project that includes HTML, CSS, and JavaScript files. Below are the details on how to set up and run the project.

## Project Structure

```
static-web-project
├── src
│   ├── index.html        # Main HTML document
│   ├── css
│   │   └── styles.css    # Styles for the web application
│   └── js
│       └── main.js       # JavaScript code for interactivity
├── public
│   └── assets
│       └── fonts         # Directory for font files
├── .gitignore            # Git ignore file
├── package.json          # npm configuration file
└── README.md             # Project documentation
```

## Getting Started

1. **Clone the repository**:
   ```
   git clone <repository-url>
   cd static-web-project
   ```

2. **Install dependencies**:
   ```
   npm install
   ```

3. **Run the project**:
   You can open `src/index.html` in your web browser to view the project.
